# Content exam (CT)

> What does this page say that no other page says?

### CT-01 Know the audience
**Question:** What do they already know, so we can skip it?
**Test:** Name the reader's level. Flag intros and sections that explain what this reader already knows.
**Healthy:** The page starts where the reader is.

### CT-02 Plan it
**Question:** Does anyone actually search for this, or do we just want to write it?
**Test:** Tie each existing or planned page to a demand source: a keyword group (KW-06), Search Console queries, support tickets, sales calls or forum threads.
**Healthy:** Every page has a reason to exist that came from a reader.

### CT-03 Write it well
**Question:** Word count barely matters. What are we adding instead of words?
**Test:** List what the page adds: original data, worked examples, code that runs, screenshots, first-hand experience, a clear recommendation. Flag padding.
**Healthy:** The list of additions is longer than the padding.

### CT-04 Optimise the opening
**Question:** Does our intro state something, or warm up?
**Test:** Read the first sentence of the page and of each section. Is it a direct, declarative claim or answer?
**Healthy:** No "In this article, we will explore…". Declarative openings correlated with higher ChatGPT citation rates across seven industries (see sources).

### CT-05 Try other formats
**Question:** Does this need to be an article, or is it a table, a calculator or a chart?
**Test:** Match format to the query: comparison → table, numbers → calculator, process → steps, change over time → chart. Check which format ranks (KW-04).
**Healthy:** The format is the fastest route to the answer.

### CT-06 Update and repurpose
**Question:** When did we last touch this page?
**Test:** Check the visible date and `dateModified`, plus outdated numbers, versions, screenshots and links. With Search Console, find pages whose clicks declined over 3–6 months.
**Healthy:** Refreshed with real changes. Changing only the date is not an update.
